## 4. Import into Terraform

Edit the bucket name in `backend.hcl` first (`cp backend.hcl.example backend.hcl`).

```bash
(

)
```

## 7. Never, after migrating

- Never run `copilot app delete`, `copilot env delete`, `copilot env deploy` or `copilot app upgrade` against a retained or migrated stack. They re-render templates without the Retain policies and can modify imported resources.
- After a partial migration, only `copilot svc deploy` of *unmigrated* workloads is allowed. Afterwards, re-run `ecsodus verify-retain`.
