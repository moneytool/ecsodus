# ADR-0009: Keep the GitHub repo private until the AWS run passes

- Status: accepted
- Date: 2026-09-29
- Deciders: maintainer

## Decision
`github.com/moneytool/ecsodus` is private. It goes public only after the real AWS run passes and
the maintainer decides to publish. Pushes follow the maintainer's working-hours rule: never
08:00–17:00 on weekdays.
