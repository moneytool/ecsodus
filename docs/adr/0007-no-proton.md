# ADR-0007: No Proton tooling

- Status: accepted
- Date: 2026-09-29
- Deciders: maintainer; council round 1 (all three)

## Decision
There is no Proton tooling. Proton reaches end of support on 2026-10-07, and after that the Proton
API is gone. What is left is generic CloudFormation adoption, which extract-cf2tf covers. One docs
page will point there.
